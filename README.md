## 🚀 **Get Started**

```python
monitor = RealTimeSemanticMonitor()

    'live_prediction': {'role': 'prediction'},
    'integration': {'role': 'integration'}
})

result = monitor.monitor('live_prediction', 
                        inputs={'data': 'stream'},
                        outputs=[0.95], 
                        base_time=120)
```
